## 关键技术实现

### 1. 输入框居中（首屏）

通过条件 CSS 注入，根据 `st.session_state.messages` 是否为空切换位置：

```python
has_messages = len(st.session_state.messages) > 0
if not has_messages:
    # 居中：bottom: 18vh
else:
    # 沉底：bottom: 1rem
```

### 2. 消除 Streamlit 默认深色背景

Streamlit 的 `stChatInput` 容器有多层嵌套，每层都有深色背景。用通配符逐层清除：

```css
[data-testid="stChatInput"] *,
[data-testid="stChatInput"] *::before,
[data-testid="stChatInput"] *::after {
    background-color: transparent !important;
    border-color: transparent !important;
}
```

然后单独给 textarea 设置暖灰色背景覆盖回来。

### 3. Upload 按钮精简

- 隐藏拖拽区文字（`section > div > div > small/span` 设 `display: none`）
- 去掉边框和背景，只留按钮
- 按钮做成小图标样式（透明底、暖灰文字）
- fixed 定位跟随输入框

### 4. 背景颗粒纹理

用 SVG feTurbulence 生成细微颗粒感：

```css
background-image: url("data:image/svg+xml,...");
```

### 5. 主内容区底部留白

防止聊天记录被固定输入框遮挡：

```css
.block-container { padding-bottom: 5rem !important; }
```
