## 第一部分：Git 基础学习

### 1.1 Git 是什么？

**定义：** Git 是一个分布式版本控制系统，用于跟踪文件的更改。

**比喻：** 就像给你的代码拍"快照"，每次提交都保存一个版本，可以随时回溯。

### 1.2 核心概念

| 概念 | 说明 | 比喻 |
|------|------|------|
| **工作区** | 你正在编辑的文件 | 你的书桌 |
| **暂存区** | 准备提交的修改 | 待发货区 |
| **本地仓库** | 提交后的版本历史 | 你的仓库 |
| **远程仓库** | GitHub 上的仓库 | 云端仓库 |

### 1.3 基本命令详解

#### 初始化仓库
```bash
git init
```
**作用：** 在当前目录创建 `.git` 隐藏文件夹，Git 开始跟踪这个项目。

**输出：**
```
Initialized empty Git repository in C:/Users/xxx/project/.git/
```

#### 查看状态
```bash
git status
```
**作用：** 查看当前 Git 的状态，包括：
- 当前在哪个分支
- 有哪些修改
- 有哪些未跟踪的文件

**输出示例：**
```
On branch main
No commits yet
Untracked files:
  (use "git add <file>..." to include in what will be committed)
        .gitignore
        pyproject.toml
```

#### 添加到暂存区
```bash
git add .
```
**作用：** 把所有修改添加到暂存区（准备提交的状态）

**注意：** `add` 后面的 `.` 表示添加所有文件

#### 提交到本地仓库
```bash
git commit -m "Initial commit"
```
**作用：** 把暂存区的所有修改保存为一个版本

**参数解释：**
- `-m` 表示后面跟的是提交信息
- `"Initial commit"` 是本次提交的描述

#### 查看历史
```bash
git log
```
**作用：** 查看所有提交记录

**简洁模式：**
```bash
git log --oneline
```

**输出示例：**
```
fae900f (HEAD -> main) Initial commit
```

### 1.4 .gitignore 文件

**作用：** 告诉 Git 哪些文件不要跟踪

**内容：**
```gitignore
# 虚拟环境
.venv/

# IDE 配置
.idea/

# Python 缓存
__pycache__/
*.pyc
*.pyo

# 环境变量（含密钥）
.env

# SQLite 临时文件
*.db-shm
*.db-wal
```

**为什么重要：**
- 防止泄露敏感信息（如 API 密钥）
- 避免提交不必要的文件
- 减少仓库大小

### 1.5 Git 工作流程

```
编辑文件 → git add → git commit → (可选) git push
   ↓         ↓          ↓              ↓
 工作区    暂存区     本地仓库       远程仓库
```

## 第二部分：LangGraph 基础学习

### 2.1 LangGraph 是什么？

**定义：** LangGraph 是 LangChain 的扩展，用于构建有状态的、多步骤的 AI 工作流。

**比喻：** 把 AI 工作流画成流程图，每个节点是一个处理步骤，边是步骤之间的连接。

### 2.2 与 LangChain 的区别

| 特性 | LangChain | LangGraph |
|------|-----------|-----------|
| **执行方式** | 链式调用（A→B→C） | 图形工作流（可以循环、分支） |
| **状态管理** | 手动传递 | 自动管理 |
| **条件分支** | 复杂 | 简单 |
| **循环** | 不支持 | 支持 |
| **中断恢复** | 不支持 | 支持 |

### 2.3 核心概念详解

#### State（状态）

**定义：** 工作流中传递的数据结构

**代码：**
```python
from typing import TypedDict, Annotated, Sequence
from langchain_core.messages import BaseMessage
from langgraph.graph.message import add_messages

class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], add_messages]
```

**解释：**
- `TypedDict`：定义字典的类型
- `Annotated`：添加元数据
- `add_messages`：告诉 LangGraph 如何合并消息

#### Node（节点）

**定义：** 工作流中的每个处理步骤

**代码：**
```python
def agent_node(state: AgentState):
    """AI 模型思考并决定是否调用工具"""
    messages = state["messages"]
    system_message = SystemMessage(content=system_prompt)
    response = model.invoke([system_message] + messages)
    return {"messages": [response]}
```

**解释：**
- 接收 `state` 作为输入
- 处理数据
- 返回更新后的 `state`

#### Edge（边）

**定义：** 步骤之间的连接

**代码：**
```python
# 无条件边
workflow.add_edge("agent", "tools")

# 条件边
workflow.add_conditional_edges(
    "agent",
    should_use_tools,
    {
        "tools": "tools",  # 需要工具 → 调用工具
        END: END           # 不需要 → 结束
    }
)
```

#### Condition（条件）

**定义：** 根据条件选择不同的路径

**代码：**
```python
def should_use_tools(state: AgentState):
    """判断是否需要调用工具"""
    last_message = state["messages"][-1]
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"
    return END
```

### 2.4 工作流程图

```
用户输入
    ↓
┌─────────────┐
│ agent_node  │ ← AI 思考
└──────┬──────┘
       ↓
┌─────────────┐
│ 需要工具？   │ ← should_use_tools
└──────┬──────┘
   是 ↓    否 ↓
┌─────────┐  ┌─────┐
│tools    │  │ END │
└────┬────┘  └─────┘
     ↓
  回到 agent
```

### 2.5 完整代码示例

```python
# 1. 定义 State
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], add_messages]

# 2. 定义 Tools
@tool
def search_recipe(query: str) -> str:
    """搜索菜谱"""
    from langchain_tavily import TavilySearch
    search = TavilySearch(max_results=3)
    result = search.invoke(query)
    return str(result)

# 3. 定义模型
model = ChatOpenAI(model="mimo-v2.5").bind_tools([search_recipe])

# 4. 定义 Nodes
def agent_node(state: AgentState):
    messages = state["messages"]
    system_message = SystemMessage(content="你是一名私人厨师...")
    response = model.invoke([system_message] + messages)
    return {"messages": [response]}

tool_node = ToolNode([search_recipe])

# 5. 定义 Conditions
def should_use_tools(state: AgentState):
    last_message = state["messages"][-1]
    if hasattr(last_message, "tool_calls") and last_message.tool_calls:
        return "tools"
    return END

# 6. 构建 Graph
workflow = StateGraph(AgentState)
workflow.add_node("agent", agent_node)
workflow.add_node("tools", tool_node)
workflow.set_entry_point("agent")
workflow.add_conditional_edges("agent", should_use_tools, {"tools": "tools", END: END})
workflow.add_edge("tools", "agent")
graph = workflow.compile()

# 7. 运行
result = graph.invoke({"messages": [HumanMessage(content="我有番茄和鸡蛋")]})
```

```python
def chat_stream(messages):
    """流式聊天 - 使用 LangGraph"""
    input_messages = []
    for msg in messages:
        if msg["role"] == "user":
            content = msg["content"]
            if isinstance(content, list):
                input_messages.append(HumanMessage(content=content))
            else:
                input_messages.append(HumanMessage(content=content))

    for chunk in graph.stream({"messages": input_messages}):
        if "agent" in chunk:
            agent_output = chunk["agent"]
            if "messages" in agent_output:
                for msg in agent_output["messages"]:
                    if isinstance(msg, AIMessage) and msg.content:
                        yield msg.content
```

## 第四部分：报错汇总与解决

### 报错 1：ModuleNotFoundError

**报错信息：**
```
ModuleNotFoundError: No module named 'app.agents'; 'app' is not a package
```

**原因：** `app.py` 文件名和 `app` 目录冲突，Python 找到 `app.py` 就认为是 `app` 模块，不会去找 `app` 目录。

**解决：** 重命名 `app.py` 为 `streamlit_app.py`

```powershell
Move-Item app.py streamlit_app.py
```

**预防：** 避免文件名和目录名相同

---

### 报错 2：IndentationError

**报错信息：**
```
IndentationError: unexpected indent
```

**原因：** 代码缩进不正确，或者代码重复

**解决：** 检查缩进，删除重复代码

**示例：**
```python
# 错误：重复代码
        if "偏好" in user_input:
            save_preference(user_input)

    except Exception as e:
        st.error(f"出错了：{e}")

            # 重复的代码
            if "偏好" in user_input:
                save_preference(user_input)

        except Exception as e:
            st.error(f"出错了：{e}")

# 正确：删除重复
        if "偏好" in user_input:
            save_preference(user_input)

    except Exception as e:
        st.error(f"出错了：{e}")
```

### 报错 3：'list' object has no attribute 'strip'

**报错信息：**
```
AttributeError: 'list' object has no attribute 'strip'
```

**原因：** `msg.content` 返回的是列表而不是字符串，不能调用 `.strip()` 方法

**解决：** 检查 content 类型

```python
# 错误
if msg.content.strip():

# 正确
content = msg.content
if isinstance(content, list):
    for item in content:
        if isinstance(item, dict) and item.get("type") == "text":
            content = item.get("text", "")
if isinstance(content, str) and content.strip():
    yield content
```

### 报错 4：write_stream() got an unexpected keyword argument

**报错信息：**
```
TypeError: WriteMixin.write_stream() got an unexpected keyword argument 'unsafe_allow_html'
```

**原因：** `st.write_stream` 不支持 `unsafe_allow_html` 参数

**解决：** 移除该参数

```python
# 错误
st.write_stream(chat_stream(all_messages), unsafe_allow_html=True)

# 正确
st.write_stream(chat_stream(all_messages))
```

### 报错 5：'function'

**报错信息：**
```
KeyError: 'function'
```

**原因：** 调试信息中访问 `tool_calls` 的方式错误，假设是字典但实际上是对象

**解决：** 使用正确的属性访问方式

```python
# 错误
tool_names = [tc['function']['name'] for tc in response.tool_calls]

# 正确
tool_names = [tc.name if hasattr(tc, 'name') else str(tc) for tc in response.tool_calls]
```

### 报错 6：list index out of range（流式输出）

**报错信息：**
```
IndexError: list index out of range
```

**原因：** 流式输出的最后一个 chunk 可能没有完整的数据

**解决：** 添加更严格的检查

```python
# 错误
if chunk.choices[0].delta.content:

# 正确
if chunk.choices and chunk.choices[0].delta and chunk.choices[0].delta.content:
```

### 报错 7：AI 返回工具调用格式但不支持

**报错信息：**
